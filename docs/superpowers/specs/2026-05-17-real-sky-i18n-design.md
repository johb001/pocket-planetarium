# 真实星图与中英文切换设计说明

## 目标

把 Pocket Planetarium 从“生成式玩具星空”升级为“基于真实亮星和观测时间地点的互动星图”，同时提供中文和 English 两套界面文案。升级后的应用仍然保持单页、无后端、可离线构建、可在浏览器里直接体验。

## 范围

第一版真实星图升级包含：

- 使用真实恒星数据替代当前随机生成星表。
- 支持观测地点：纬度、经度和常用城市快捷项。
- 支持观测时间：日期、时间和“现在”按钮。
- 根据地点和时间把赤经/赤纬转换为地平坐标，再投影到 Canvas。
- 显示太阳、月亮和可见行星的近似位置。
- 页面文案支持中文和 English，一键切换并记住选择。

第一版不包含：

- 完整 88 星座边界。
- 高精度天文历算校验界面。
- 联网实时定位强依赖。
- 后端账户、云同步或付费 API。

## 数据来源

恒星数据使用 HYG 星表的亮星子集。构建时从 CSV 中筛选适合浏览器展示的字段，并保存为项目内静态数据。字段包括 id、常用名、拜耳/弗兰斯蒂德名、赤经、赤纬、视星等、颜色指数和距离。运行时不下载大型 CSV。

太阳、月亮和行星位置使用 `astronomy-engine` 的 JavaScript 包在浏览器内计算。它负责天体赤经/赤纬或地平坐标计算，项目负责把结果投影到当前 Canvas。

如果构建时无法取得完整 HYG 数据，项目保留一个项目内亮星样本作为降级数据，保证应用可运行、测试可跑、页面不空白。

## 架构

新增和调整模块：

- `src/i18n/messages.ts`：中文和英文文案字典。
- `src/i18n/locale.ts`：语言检测、切换和 localStorage 持久化。
- `src/sky/realCatalog.ts`：真实亮星静态数据导出。
- `src/sky/coordinates.ts`：儒略日、恒星时、赤经赤纬到高度角/方位角、屏幕投影。
- `src/sky/solarSystem.ts`：封装 `astronomy-engine`，返回太阳、月亮和行星的显示点。
- `src/sky/catalog.ts`：从生成星表切换为真实星表适配层，保留 `StarCatalog` 供渲染层使用。
- `src/main.ts`：加入地点、日期时间、语言切换、当前位置尝试和“现在”按钮。

保留模块：

- `src/sky/render.ts` 继续负责 Canvas 绘制。
- `src/sky/hitTest.ts` 继续负责点击命中。
- `src/state/observations.ts` 继续负责观测卡片。

## 数据流

应用状态扩展为：

- `locale`：`zh` 或 `en`。
- `observer`：纬度、经度、地点标签。
- `observedAt`：ISO 时间字符串。
- `selectedStarId`：选中的恒星或天体 id。
- 现有的图层开关和观测卡片列表。

渲染流程：

1. 根据当前 `observer` 和 `observedAt` 计算天空上下文。
2. 把真实恒星的赤经/赤纬转换为高度角和方位角。
3. 过滤地平线以下的对象。
4. 把可见对象投影到 Canvas。
5. 渲染恒星、星座辅助线、太阳/月亮/行星、标签和选中对象。
6. UI 文案根据 `locale` 从字典读取。

## 中英文体验

语言切换在控制栏顶部使用分段按钮：

- `中文`
- `English`

默认策略：

- 如果 localStorage 中已有语言选择，优先使用。
- 否则根据浏览器语言选择中文或英文。
- 其他语言默认英文。

需要双语覆盖的内容：

- 控件标签、按钮、空状态、错误提示。
- 星星详情字段名。
- 太阳、月亮和行星名称。
- 观测卡片默认标题。
- README 中新增双语功能说明。

真实恒星名称优先使用通用专名；没有专名时显示目录名。中文界面里保留常见英文星名，避免不准确翻译。

## 错误处理

- 浏览器拒绝定位时，使用默认地点：香港。
- 地点输入无效时，保留上一次有效地点并显示简短错误。
- 时间输入无效时，使用当前时间。
- `astronomy-engine` 计算失败时，只渲染恒星并隐藏太阳系天体层。
- localStorage 损坏时，沿用现有策略清空相关数据。

## 测试

新增 Vitest 覆盖：

- 语言检测、切换、localStorage 持久化。
- 文案 key 在中文和英文中完整一致。
- 赤经/赤纬到高度角/方位角的已知边界案例。
- 地平线以下对象不参与命中测试。
- 真实星表加载后包含亮星且字段合法。
- 太阳系封装在给定时间地点下返回稳定结构。

保留现有测试：

- 命中测试。
- 观测卡片持久化。
- 时间显示逻辑，但会调整为真实时间上下文。

## 交付

完成后需要：

- 更新 GitHub 仓库。
- 保持 `npm test` 和 `npm run build` 通过。
- 浏览器冒烟测试覆盖：切换语言、修改地点/时间、Canvas 非空、保存观测。
- README 说明真实星图数据来源、精度边界和双语使用方式。
