# Pocket Planetarium

Pocket Planetarium 是一个口袋星象馆原型：主界面以全屏 Canvas 展示星空，控制 dock 用于调整夜间时间、星座线、标签和观测记录。

## 环境要求

- Node.js 18 或更高版本
- npm 9 或更高版本

## 安装

```bash
npm install
```

## 本地开发

```bash
npm run dev
```

启动后按终端提示打开本地地址。开发服务器默认绑定到 `127.0.0.1`。

## 测试

```bash
npm test
```

该命令会运行 Vitest 测试，用于验证星表、命中测试、时间状态和观测记录逻辑。

## 构建

```bash
npm run build
```

构建流程会先执行 TypeScript 检查，再由 Vite 输出生产资源到 `dist/`。

## 使用方式

1. 打开应用后，星空会铺满整个窗口。
2. 使用控制 dock 调整夜间时间，观察星空旋转和标签密度变化。
3. 切换星座线或星名标签，按需减少画面信息。
4. 点击或点按星星可选中目标，选中状态会在星图上高亮。
5. 保存观测记录后，可从记录列表恢复当时的夜间时间和选中星星。

## 样式说明

- `src/styles.css` 提供全屏 Canvas、半透明控制 dock、移动端触控尺寸和常见控件状态。
- 控制 dock 会复用 `src/assets/field-panel.png` 作为低调纹理。
- 视觉基调混合暖色、冷绿和深色底，不依赖单一蓝紫配色，也不包含营销页或装饰性光斑。
